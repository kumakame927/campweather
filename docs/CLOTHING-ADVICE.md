# 服装・装備アドバイス

詳細モーダルの既存欄を「日中のおすすめ服装」「夜間〜早朝のおすすめ服装」「追加の装備・注意事項」の3つにする。一覧カードの情報・デザイン・ランキングは変更しない。新しいAPI、取得項目、ライブラリ、保存データは追加しない。

## 体感温度と実気温

判定は `src/clothing-advice.js`、時間帯は既存集計と共通の `comfortWindows` で管理する。

- 日中：開始日12:00〜16:00の5時刻の平均体感温度。
- 夜間：開始日18:00〜翌日09:00の16時刻の最低体感温度。
- 各時間帯で最低実気温も求め、**体感の代表値と最低実気温の低い方**を服装の目安に使う。体感が高めでも低い実気温を無視しない。画面に平均/最低体感と最低実気温を表示し、補正時は説明を添える。
- 必要な体感温度または実気温が1時刻でも欠ければ、その時間帯の服装は判定せず不足を表示する。気温から体感温度を作ったり、欠測を0で補ったりしない。
- 日帰りは夜間対象外。2泊3日は、既存の指標と同じ開始日と最初の夜を対象にし、画面で明記する。日付や月末をまたぐ計算は日本時間のISO文字列を使う。

`CLOTHING_BANDS` の基準は以下。キャンプ向けの暫定的な一般目安であり、安全・快適性を保証しない。

| 判定温度 | 衣類 |
| --- | --- |
| 25℃以上 | 半袖・通気性のよい服装 |
| 20℃以上25℃未満 | 長袖シャツ・薄手の羽織り |
| 15℃以上20℃未満 | 長袖シャツ＋薄手ジャケット |
| 10℃以上15℃未満 | スウェット・フリース＋防風アウター |
| 5℃以上10℃未満 | フリース＋薄手ダウン |
| 5℃未満 | 厚手ダウン＋保温インナー・手袋・ニット帽 |

夜間の判定温度20℃未満では、長時間屋外で座る場面を想定し保温性のある靴下・ブランケットも案内する。個人差と、体感温度がテント内・寝具内の温度や寝袋の快適温度ではないことを明記する。焚き火の暖房効果は計算しない。

## 風雨・寒暖差

閾値は `ADVICE_THRESHOLDS` にまとめる。

| 条件 | 追加案内 |
| --- | --- |
| 風速5m/s以上 | 防風アウター |
| 風速8m/s以上 | 上記に加え、テント固定・設営場所・焚き火可否と施設ルールの確認 |
| 降水確率40%以上 | レインウェア・防水靴・荷物用防水バッグ |
| 降水確率70%以上 | 雨天装備と、濡れたときに交換する衣類・靴下 |
| 寒暖差10℃以上 | 重ね着できる服装 |
| 寒暖差15℃以上 | 日中と夜間で異なる防寒装備が必要な可能性と、夜用保温着の準備 |

風雨は選択した全日程について、取得済みの日別最大値と時間別値の最大を使う。日別が不足していても時間別が全時刻あれば判定できる。両方不完全でも既知の高い値による注意は省略せず「取得できた予報では○以上」と示し、不足も別途表示する。低い値だけで強風や雨の可能性がないとは判断しない。

寒暖差は既存の日中最高実気温 − 夜間最低実気温を使う。必要な時刻が不足した場合は追加装備の判断に使わない。

風・雨・寒暖差はそれぞれ強い条件を1件だけ表示する。例えば降水確率70%では40%の雨具案内を別に重ねない。防風アウターが上の服装で既に案内されている場合、追加欄に同じ衣類を繰り返さず、強風時の設営・焚き火の注意は残す。

## 検証

`tests/clothing-advice.test.js` に17項目を追加する。

| 指定ケース | 日中 | 夜間 |
| --- | --- | --- |
| 25℃ / 18℃ | 半袖・通気性のよい服装 | 長袖シャツ＋薄手ジャケット |
| 20℃ / 10℃ | 長袖シャツ・薄手の羽織り | スウェット・フリース＋防風アウター |
| 15℃ / 5℃ | 長袖シャツ＋薄手ジャケット | フリース＋薄手ダウン |
| 10℃ / 0℃ | スウェット・フリース＋防風アウター | 厚手ダウン＋保温インナー・手袋・ニット帽 |

表のケースは体感温度と実気温が同じ場合。実気温が低い補正、全境界値、風速8m/s、降水確率70%、寒暖差15℃、時刻欠測、単位異常、日帰り/2泊、部分取得、予報を変更しないことも検証する。

`tests/details-browser.js` に指定8ケースを追加し、Chromium/WebKitで3表示欄、具体的な衣類、注意の重複防止、320/390px、追加API呼び出しなし、カードの項目数不変を確認する。既存の検索・お気に入り・日程/ランキング・地図登録・JMA・PWA保存のテストも実行する。
