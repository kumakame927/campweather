# 時間別予報・体感温度・詳細表示

## 既存構成の確認

- `src/weather.js` がOpen-Meteoの日別天気・最大降水確率・最高/最低気温・最大風速を取得・検証する。ViteプレビューとVercelは同一オリジンの中継、静的ビルドは従来の直接接続を維持する。
- `src/main.js` の `dayColumn` / `render` が比較カードを描画する。独立したコンポーネントフレームワークは使用していない。
- 既存の `compareForecasts` は最終日の降水確率 → 日程中の最大風速 → 最終日以外の最大降水確率 → 名称で比較する。追加した体感温度や寒暖差は順位に使用しない。土日1泊なら日曜日の降水確率が最優先となる。
- `src/library.js` のお気に入りと比較対象は独立している。取得するのは比較対象だけで、今回も既存のlocalStorageキー・保存形式・移行・バックアップを変更しない。
- 同じ座標・日程で30分以内に取得済みの予報を、比較対象の増減時に再利用する。時間別データも同じ予報オブジェクト内に保持し、モーダルを開く際には追加リクエストを行わない。定期更新と手動更新は従来どおり。

## Open-Meteoへの追加

[公式Forecast API](https://open-meteo.com/en/docs) の `hourly` に以下を指定する。

- `temperature_2m`
- `apparent_temperature`
- `precipitation_probability`
- `wind_speed_10m`
- `relative_humidity_2m`
- `weather_code`

以前は日別項目だけを指定していたため、6つの時間別変数を同じリクエストに追加する。通常は施設ごとに1回のまま。`timezone=Asia/Tokyo`、`wind_speed_unit=ms`、`temperature_unit=celsius` と、選択日程の `start_date` / `end_date` を使う。必要な日付だけ取得し、追加のライブラリ・APIキー・有料サービスは導入しない。変数と時間別配列の追加によって応答サイズは増える。

`src/hourly.js` はAPIが返す `timezone=Asia/Tokyo` と `utc_offset_seconds=32400` を確認し、ローカルISO時刻をJSTの文字列として対応付ける。端末タイムゾーンによる変換を行わない。各変数の単位・有限数値・範囲を検証する。重複時刻、欠けた配列、異なる単位、不正値はその項目を欠測にする。体感温度はAPIの値を読み取り、気温・湿度等から独自計算しない。

時間別配列が欠落・不正でも日別予報の検証と順位計算には影響させない。追加したリクエストがHTTP 400で拒否された場合に限り、日別項目だけで一度取得を試みる。429・403・通信失敗等では不要な再試行を行わない。

## 集計

毎正時の予報を使い、以下の範囲の両端を含む。必要な時刻の対象変数が1つでも欠ける場合、当該集計を算出せず `--` を表示する。別の値で補完したり、0として扱ったりしない。

| 指標 | 土日1泊の場合 | 必要な値 |
| --- | --- | --- |
| 日中最高 | 土曜12:00〜16:00の気温の最大値 | 5時刻の気温 |
| 夜間最低 | 土曜18:00〜日曜09:00の気温の最小値 | 16時刻の気温 |
| 寒暖差 | 上記の日中最高 − 夜間最低 | 両方の完全な集計 |
| 最低体感 | 土曜18:00〜日曜09:00の体感温度の最小値 | 16時刻の体感温度 |
| 日曜の日内寒暖差 | 日曜00:00〜23:00の気温最大 − 最小 | 24時刻の気温 |

既存の日程選択を維持する。平日の1泊も開始日/翌日に同じ時間帯を当てはめ、実際の日付を表示する。日帰りは夜間最低・最低体感・昼夜の寒暖差が対象外。2泊3日は開始日と最初の夜で集計し、その旨を明記する。日内寒暖差は選択日程の最終日の24時間を対象とし、全日程の時間別表とグラフを確認できる。

## UIと操作

緑の既存デザイン、日ごとの天気・降水確率・最大風速を維持する。従来の各日の最高/最低欄をコンパクトな日中最高/夜間最低・寒暖差・最低体感・短評へまとめる。日別最高/最低の値は詳細に残す。

カードの通常領域をタップ、またはキャンプ場名の「詳細」ボタンをキーボードで押すと、ネイティブの `dialog` を開く。既存のボタン・リンク・住所詳細・JMA折りたたみ操作は除外する。閉じるボタン・Esc・背景クリックに対応し、フォーカスと一覧位置を戻す。モーダルは縦スクロールでき、閉じるボタンを上部に固定する。開いたまま予報が更新された場合も日付の選択とフォーカスを保つ。

SVGの折れ線グラフで気温（緑の実線）と体感温度（茶色の破線）を表示し、欠測の前後をつながない。日付で切り替える24時間表で、天気・気温・体感温度・降水確率・風速・湿度を表示する。追加のグラフライブラリは使用しない。

服装は日中の平均体感温度・夜間の最低体感温度を6段階で判定し、最低実気温が低ければ寒い側へ補正する。風速・降水確率・寒暖差による追加装備も案内する。欠測時は服装を断定しない。安全性や快適性を保証する判定ではなく、屋外の体感温度をテント内気温や寝袋の快適温度と混同しない旨を明記する。[詳細な判定ルール・閾値・検証](CLOTHING-ADVICE.md)を参照。

テスト用の予報は `tests/fixtures/hourly.js` のみに置き、本番コードから参照しない。実機iPhone固有のOS動作はWebKitエミュレーションだけでは保証しない。
