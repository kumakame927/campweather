# 検索用キャンプ場データ

`campgrounds.json` はOpenStreetMapのcamp_site / caravan_siteを対象10都県から抽出・整形した派生データベースです。

© OpenStreetMap contributors. Open Database License (ODbL) 1.0で提供します。

- 出典・著作権：https://www.openstreetmap.org/copyright
- ライセンス本文：https://opendatacommons.org/licenses/odbl/1-0/
- 抽出コード：`scripts/update-camp-catalog.mjs`
- 生データの取得元：https://overpass-api.de/

JSONファイルを取得・再利用・改変・再配布する際はODbLの出典・共有条件に従ってください。アプリのプログラムとデータベースのライセンスを混同しないでください。利用条件の詳細と更新方式はリポジトリの `docs/CATALOG-LIBRARY.md` を参照してください。
